Manual Wi‑Fi setup

Browser cannot turn on Wi‑Fi Direct itself. Do this on both phones, then return here.

Android — create hotspot (easiest)
  1. Open Settings → Network & internet → Hotspot
  2. Turn on Mobile hotspot
  3. Note the hotspot name + password
  4. On the other phone: join that Wi‑Fi hotspot
Android — Wi‑Fi Direct (if available)
  1. Settings → Network & internet → Wi‑Fi → ⋮ → Wi‑Fi Direct
  2. Wait for the other phone to appear → tap to connect
Then in this app
  1. Both open this same page
  2. Use LAN Connect in Settings to link the two browsers
  3. Or search by ID if using same device / shared storage
